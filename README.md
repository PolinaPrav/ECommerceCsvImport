# ECommerceCsvImport — модуль импорта товаров из CSV

Производственная практика **ПП.02.01**, профессиональный модуль **ПМ.02 «Осуществление интеграции программных модулей»**, специальность 09.02.07 «Информационные системы и программирование».

**Тема индивидуального задания:** разработка модуля импорта товаров в электронный магазин из CSV-файлов с хранением данных в коллекциях в памяти.

**Вариант:** 1 «Электроника» (дополнительные поля `brand`, `warranty_months`, `model_number`).

**Автор:** Правденкова Полина, группа ИПо-42.
**Руководитель практической подготовки:** Берестов Дмитрий Борисович.

## Что делает программа

Программа читает CSV-файл с товарами, проверяет каждую строку, добавляет правильные товары в список в памяти и показывает результат импорта: сколько строк всего, сколько импортировано, сколько ошибок и список ошибок с номерами строк. Загруженные товары можно посмотреть на отдельной странице.

База данных не используется. Товары хранятся в `List<Product>` и пропадают после перезапуска приложения (так разрешено заданием).

## Что реализовано

- чтение CSV-файла по пути: относительно `wwwroot` (например `/csv/sample_products.csv`) или полный путь на диске;
- свой разбор строки CSV (`CsvLineParser`) с поддержкой пустых полей, запятых внутри кавычек и экранированных кавычек `""`, без внешних библиотек;
- преобразование строк в объекты `Product`;
- валидация всех полей, включая поля варианта «Электроника»;
- список ошибок с номерами строк (номер — физическая строка файла, заголовок — строка 1);
- хранение товаров в памяти (`InMemoryProductRepository`, потокобезопасный, зарегистрирован как singleton);
- страница импорта с таблицей результата и списком ошибок;
- страница списка товаров с количеством и общей стоимостью;
- оформление страниц в тёмной теме;
- повторный импорт без падения приложения (дубликаты артикулов пропускаются, добавляется ошибка);
- модульные тесты xUnit.

Из дополнительных элементов задания (п. 11.2) сделаны подсчёт общего количества и стоимости товаров и unit-тесты. Остальные необязательные пункты (загрузка файла через браузер, поиск, фильтры, сортировка, экспорт) не делала.

## Технологии

C#, .NET 8, ASP.NET Core MVC, Bootstrap, xUnit, Git.

## Запуск

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

**Visual Studio 2022:** открыть `ECommerceCsvImport.sln`, запускаемый проект — `ECommerceCsvImport`, нажать F5.

**Командная строка:**

```bash
dotnet run --project ECommerceCsvImport
```

Адрес по умолчанию: http://localhost:5171 (главная страница сразу открывает список товаров).

**Импорт:** кнопка «Импортировать товары из CSV» → в поле ввести `/csv/sample_products.csv` → «Импортировать товары». Чтобы увидеть товары, нажать «Перейти к списку товаров».

**Тесты:**

```bash
dotnet test
```

## Архитектура

```
CSV-файл
   ↓
ProductsController   (принимает путь, сам файл не читает и данные не проверяет)
   ↓
ProductImportService → CsvLineParser   (чтение, разбор полей, валидация)
   ↓
InMemoryProductRepository   (List<Product>, singleton)
   ↓
ProductsController → Views (Import.cshtml, Index.cshtml)
```

Контроллер тонкий: вся логика импорта находится в сервисе, хранение данных отделено в репозитории. Репозиторий и сервис зарегистрированы через `AddSingleton`, чтобы данные не терялись между HTTP-запросами (при `AddScoped` список товаров был бы пустым после перехода со страницы импорта).

## Формат CSV

Первая строка — заголовки, разделитель — запятая, кодировка UTF-8.

```
sku,name,description,price,currency,category_name,stock,image_url,is_active,brand,warranty_months,model_number
1001,Ноутбук Lenovo IdeaPad 3,Бюджетный ноутбук для работы и учебы,45990,RUB,Компьютеры,5,/images/laptop.jpg,true,Lenovo,24,IdeaPad 3-15
```

| Поле | Тип | Обязательно | Правило / сообщение об ошибке |
|------|-----|-------------|-------------------------------|
| sku | string | да, уникальное | «Поле sku не может быть пустым», «Артикул товара уже существует» |
| name | string | да | «Поле name не может быть пустым» |
| description | string | нет | — |
| price | decimal | да | больше 0; «Поле price должно быть числом больше 0» |
| currency | string | нет | если пусто — `RUB` |
| category_name | string | нет | если пусто — «Без категории» |
| stock | int | да | не меньше 0; «Остаток на складе должен быть целым числом не меньше 0» |
| image_url | string | нет | — |
| is_active | bool | да | true / false / 1 / 0; «Поле is_active должно иметь значение true, false, 1 или 0» |
| brand | string | да | «Поле brand обязательно для варианта «Электроника»» |
| warranty_months | int | да | от 0 до 60; «Гарантия должна быть целым числом от 0 до 60 месяцев» |
| model_number | string | нет | — |

Ошибки уровня файла: «Файл не найден», «Данные для импорта отсутствуют», «Неверные заголовки CSV», «Неверное количество полей в строке».

## Принятые решения

- **Дубликаты SKU** (внутри файла и с уже загруженными товарами) пропускаются, в результат добавляется ошибка. Это вариант, который рекомендует задание.
- Заголовки ищутся без учёта регистра, порядок колонок может быть любым, лишние колонки игнорируются.
- В одной строке проверяются все поля сразу, поэтому у одной строки может быть несколько ошибок.
- Пустые строки пропускаются и не входят в «Всего строк».
- Ошибки файла (пустой путь, файл не найден, пустой файл, неверные заголовки) показываются в списке ошибок; для них номер строки 0, для неверных заголовков — номер строки заголовка.
- Если у строки есть ошибки, товар в память не добавляется совсем.

## Тестирование

### Автоматические тесты

В `ECommerceCsvImport.Tests/AllTests.cs` 31 тест xUnit по плану тестирования:

| Что проверяется | Количество |
|-----------------|-----------|
| Репозиторий (добавление, поиск по SKU, пустой репозиторий) | 4 |
| Парсер CSV (простая строка, пустые поля, запятая в кавычках, экранированные кавычки) | 4 |
| Сервис импорта (успешный импорт, все ошибки валидации, дубликаты, пустой и ненайденный файл, значения по умолчанию, кириллица) | 23 |

Запуск: `dotnet test`.

### Ручные сценарии через браузер

| № | Сценарий | Путь в поле импорта | Ожидаемый результат |
|---|----------|---------------------|---------------------|
| 1 | Успешный импорт | `/csv/sample_products.csv` | всего 11, импортировано 11, ошибок 0; на странице товаров 11 строк |
| 2 | Неверная цена | `/csv/bad_price.csv` | 0 импортировано, ошибка в строке 2: «Поле price должно быть числом больше 0» |
| 3 | Повторный импорт | `/csv/sample_products.csv` два раза подряд | приложение не падает, при втором разе 11 ошибок «Артикул товара уже существует» |
| 4 | Файл не найден | `/csv/nope.csv` | в списке ошибок «Файл не найден», приложение не падает |
| 5 | Пустое поле пути | (ничего не вводить) | сообщение «Укажите путь к CSV-файлу» |

Остальные случаи (пустой файл, нет бренда, гарантия вне диапазона, неверный is_active, отрицательный остаток, пустое название, дубликат внутри файла и т.д.) проверяются автоматическими тестами, так как для них строки CSV задаются прямо в коде теста.

## Самопроверка кода

| Критерий | Как выполнено |
|----------|---------------|
| Имена классов и методов | `ProductImportService`, `ImportFromCsv`, `ImportFromLines`, `GetBySku` |
| Обработка ошибок | неверный CSV не роняет приложение; `IOException` и `UnauthorizedAccessException` при чтении файла перехватываются в сервисе |
| Разделение ответственности | контроллер не читает файл и не валидирует данные |
| Потокобезопасность | в репозитории `lock`, `GetAll` возвращает копию списка |
| Git | код лежит в репозитории на GitHub: https://github.com/PolinaPrav/ECommerceCsvImport |

## Ограничения и что можно улучшить

- данные теряются при перезапуске (нет БД);
- читается только UTF-8, разделитель только запятая;
- можно добавить загрузку файла через браузер, поиск, фильтры, сортировку и экспорт в CSV.
